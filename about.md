# About nestarc

nestarc is an open-source organization building NestJS reliability modules for multi-tenant SaaS backends. The canonical website is [nestarc.dev](https://nestarc.dev/), the source repositories live in the [nestarc GitHub organization](https://github.com/nestarc), and published releases are available from the [@nestarc npm organization](https://www.npmjs.com/org/nestarc).

The organization name may overlap with unrelated businesses. The GitHub organization, npm scope, and this domain are the authoritative identity links for this software project.

## Maintainers and authorship

Documentation and package references are maintained under the **nestarc** organization identity. We do not assign a personal byline where a named author or reviewer has not been publicly established. Issues, pull requests, release commits, and repository history provide the public maintenance record for each package.

## Editorial and technical review

Technical articles declare their publication date, most recent review date, and version scope. A review checks examples and claims against the referenced package release, generated API documentation, current compatibility contract, and reproducible benchmark notes where performance figures are used.

Package status is explicit:

- **Supported** indicates the documented release is the recommended adoption path.
- **Preview** indicates a narrower contract or a release that needs additional production validation.

Neither status replaces application-specific testing, security review, legal review, or operational design. Benchmarks describe a recorded environment and are not performance guarantees.

## Corrections and verification

To report an inaccurate example or stale compatibility claim, open an issue in the relevant [GitHub repository](https://github.com/nestarc). When evaluating a claim, prefer the package documentation and generated API reference for the listed version, then verify it against the linked source and release on npm.

For general project questions, see the [Community page](/community/) and [FAQ](/faq).
